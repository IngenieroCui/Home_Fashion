# Alcance del trabajo

## Incluido

- Catálogo público, categorías, productos, variantes e imágenes por URL.
- Solicitudes públicas, clientes, cotizaciones, precios negociados, ventas, pagos y saldos.
- Pedidos con líneas `IN_STOCK` y `MADE_TO_ORDER` e inventario de muebles terminados.
- Asignación a talleres, avances append-only y revisión administrativa.
- Seguimiento privado del cliente con datos minimizados.
- Programación, despacho, recepción y evidencia URL de entregas.
- Web pública/administrativa, API REST y aplicación Android para talleres.
- Pruebas automáticas, integración, smoke E2E, evaluación con usuarios y documentación académica.

## Excluido

- Contabilidad completa, nómina, impuestos y facturación electrónica.
- Inventario de materias primas y pagos a talleres.
- Pasarela de pago real e integraciones bancarias.
- GPS, mapas, geocodificación u optimización de rutas.
- Chat interno, WhatsApp API, SMS y notificaciones push.
- Carga real de archivos, modo offline complejo e iOS.
- Multiempresa/multialmacén, microservicios, Docker, Kubernetes, Redis y analítica avanzada.

## Límites actuales

- Las evidencias son URLs; no existe upload.
- No hay despliegue productivo validado.
- MySQL real, navegador, Android contra API y recorrido E2E siguen pendientes.
- No existen todavía mediciones de usuarios ni porcentajes de mejora verificables.
