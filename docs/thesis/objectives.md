# Objetivos y evidencia esperada

## Objetivo general

Desarrollar y evaluar una plataforma web y móvil que digitalice y centralice la gestión comercial, productiva y de seguimiento de pedidos de Home Fashion, con el fin de mejorar la trazabilidad, la disponibilidad de información y la coordinación entre el negocio, los talleres y los clientes.

## Objetivos específicos

| ID | Objetivo | Evidencia mínima para considerarlo atendido |
| --- | --- | --- |
| OE1 | Caracterizar procesos, actores, requerimientos, pérdidas de trazabilidad y línea base. | Mapa del proceso actual, RF/RNF, actores, tareas comparables y mediciones de línea base. |
| OE2 | Diseñar e implementar web, API y Android integrados, con roles, trazabilidad y protección de información. | Arquitectura, modelo de datos, código, contratos, capturas y trazabilidad requisito→implementación. |
| OE3 | Verificar calidad técnica y funcional con pruebas automáticas, integración y E2E reproducible. | Logs de lint/test/build, MySQL limpio, migraciones/seeders, smoke E2E, navegador y Android contra API real. |
| OE4 | Evaluar usabilidad y contribución operativa con actores de Home Fashion. | Protocolo, consentimiento, tiempos, interacciones, finalización, errores, SUS si aplica y análisis cualitativo. |

## Regla de cierre

Un objetivo no se declara cumplido solo porque exista código. La conclusión por objetivo debe citar evidencia observada y reconocer cualquier validación pendiente o limitación del estudio.
