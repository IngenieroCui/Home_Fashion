## Contratos y límites observados

- Logout revoca refresh; JWT access es stateless y expira según JWT_ACCESS_EXPIRES_IN=15m. Desactivación bloquea peticiones protegidas, refresh y login con 401.
- USER_MANAGE está sembrado pero no tiene endpoint de usuarios en este corte: /admin/users devuelve 404. La creación/desactivación de usuarios QA se hizo con SQL parametrizado y acotado a sus IDs/email; no existe una desactivación HTTP ADMIN que probar.
- Taller puede revisar su estimación porcentual hacia abajo: permitido por la regla existente. No se inventó monotonía.
- Entregar no descuenta existencias ni libera reservas: contrato explícito de docs/architecture.md. QA no cambió ese comportamiento.
- Se probó contenido JPEG/PNG/WebP real contra Cloudinary y se eliminó cada imagen temporal por API. Validación local comprueba MIME, firma y tamaño; Cloudinary hace la decodificación.
- Multipart real/Multer/ValidationPipe con dominio/media controlados evita basura remota al ejecutar 5 imágenes y fallos posteriores a upload. Cleanup es evidencia controlada; no se afirma haber provocado un fallo remoto deliberado en la base real.
- La API del catálogo llama minPrice/maxPrice a los filtros de precio; se probaron esos nombres y el rechazo de priceMin/priceMax inesperados.
- Costos y márgenes ausentes en venta del usuario limitado. Se corrigió también la fuga de estimatedCost en catálogo con CATALOG_MANAGE sin FINANCIAL_COST_VIEW.
- No se encontraron parseInt/parseFloat en las conversiones monetarias de módulos revisados. BigInt conserva centavos; Number se usa para contadores, inventario y porcentajes.
