# Protocolo de evaluación OE4

Estado al 12 de noviembre de 2026. Sin sesiones con participantes acreditadas para este corte.

| Perfil | Tarea observada | Resultado esperado |
| --- | --- | --- |
| Comercial | Cotizar, convertir a venta y generar el pedido | El pedido refleja productos, cantidades y modalidad de suministro. |
| Taller | Consultar su trabajo, tomar fotos y enviar un avance | El avance queda disponible para revisión y no se muestra a un taller ajeno. |
| Operaciones | Revisar el avance, programar y confirmar entrega | El pedido llega a un estado consistente y las reservas se actualizan. |

Antes de cada sesión, registrar consentimiento, código del participante, perfil, contexto, fecha, SHA y dispositivo. Usar una base y cuentas de prueba. Medir tiempo desde la consigna hasta el resultado, éxito completo/parcial/fallo, intentos, errores y ayudas. Anotar la causa observada y enlazar al requisito en la matriz de trazabilidad. Informar resultados por perfil y describir tamaño de muestra, experiencia previa y limitaciones. Resguardar consentimientos y evidencias identificables fuera de Git.

Registro por tarea: código de sesión, perfil, identificador de requisito, duración, resultado, ayudas, errores y observación. Reportar tasa de éxito con denominador y tiempos con unidad. Solo presentar comparativos si se mide una línea base equivalente.
