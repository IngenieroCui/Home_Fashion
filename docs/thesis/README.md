# Espacio de trabajo de tesis de Home Fashion

Este directorio organiza los artefactos académicos que conectan la propuesta final con el repositorio y con la evidencia de validación. El código y las migraciones son la fuente de verdad técnica; la propuesta final es la fuente de verdad para objetivos, alcance y metodología.

## Principios

- `IMPLEMENTADO` no equivale a `VALIDADO`.
- No se atribuyen mejoras, resultados de usuarios ni despliegues sin evidencia observada.
- Las tesis de referencia solo orientan estructura y presentación; su contenido no se reutiliza.
- Los documentos existentes en `docs/` se enlazan y se amplían; no se duplican sin necesidad.
- Linear registra planificación y estado. Google Drive conserva documentos compartibles, diagramas y evidencias; Git conserva código y documentación técnica.
